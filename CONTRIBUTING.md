# Contributing

Thanks for considering a contribution to Awesome XTM!

## Adding a project

1. Make sure the project is relevant to the **XTM suite** (OpenCTI, OpenAEV, and their connectors/collectors/injectors) — deployment, infrastructure, developer tooling, or testing/simulation.
2. Add it to the most relevant section, in alphabetical order, using this format:

   ```markdown
   - **[Project Name](https://github.com/owner/repo)** — one or two sentence description of what it does and why it's useful.
   ```

3. Keep descriptions factual and concise (no marketing language).
4. If your project doesn't fit an existing section, feel free to propose a new one in your PR.
5. Open a pull request. New entries and corrections to existing ones are both welcome.
